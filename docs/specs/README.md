# 프로젝트 지침 원문

작업 시 제공된 기획·화면 가이드·디자인·API·상태 문서 원문과 디자인 MD에서 직접 참조하는84개 이미지를 보존했다. 큰 원본 PDF/ZIP은 이 폴더에 중복 업로드하지 않았다. Figma 원본은 문서에 기록된 링크에서 조회한다.

PROJECT_INSTRUCTIONS.md의 frontend/ 접두 경로는 작성 당시 상위 워크스페이스 기준이다. 현재 저장소에서는 frontend/ 접두어를 제거하고 읽는다. 이 폴더의 기획·API 문서 전체 구현 목록을 FE2 개인 담당 범위로 확대하지 않는다. 실제 API의 최신 코드 대조는 ../FE2_HANDOFF.md, 디자인 재검수는 ../FE2_DESIGN_RECHECK.md를 우선한다.
