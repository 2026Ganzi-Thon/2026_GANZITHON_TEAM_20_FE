## 문서의 성격과 확인 범위

원본의 9개 영역, 43개 화면·상태·보조 패턴 프레임, 40개 화면정의 가이드, 1171개 텍스트 노드를 읽었다. 화면 이름, 원문 문구, 가이드의 동작·조건·예외와 관련 노드 ID를 아래에 보존한다. 금고 목록·걱정 확인·10분 액션·기록 상세·시연 패널은 렌더 이미지도 확인했다. 대표 FE2 화면 12개의 주요 컨테이너 수치도 별도로 기록했다.

프로토타입 반응을 읽은 시점에는 와이어프레임 페이지의 3,646개 노드에서 설정된 반응이 **0개**였다. 아래 이동 관계는 **화면 가이드와 레이어 이름의 화살표 표기**를 근거로 정리한 것이며, 실제로 연결·실행되는 프로토타입을 테스트했다는 뜻이 아니다.

이 문서는 와이어프레임 참고 자료다. UI 페이지의 최종 색·폰트·일러스트·모션, 실제 API 명세와 구현 코드는 아직 이 문서의 확인 대상이 아니다. 예시 날짜·개수·내용·불안도·글자 수는 화면 샘플이며 실제 값처럼 하드코딩하지 않는다.

## 읽는 순서

1. FE2 담당표와 핵심 동작 기준을 먼저 읽는다.
2. 해당 화면의 원문·화면 가이드·전환 표기를 읽는다.
3. 공통 상태와 보조 창, 다른 담당 화면과의 연결을 확인한다.
4. 수치 참고와 검증 체크리스트를 사용한다.
5. 아직 정해지지 않은 항목은 임의로 확정하지 않고 팀 명세와 연결한다.

## FE2 핵심 동작 기준

### 금고·잠금과 공개

- S-07은 ‘열어볼 수 있어요’와 ‘아직 잠겨 있어요’를 구분하고 각 영역을 작성 시각 최신순으로 표시한다.
- 공개 행은 작성 일시·한 줄 요약·봉인 전 불안도, 잠김 행은 작성·공개 일시만 표시한다.
- 공개 전에는 원문·선택 메모·AI 요약·불안도를 응답과 표시 단계에서 보호한다. 단순 CSS 숨김으로 서버 접근 검사를 대신하지 않는다.
- 목록에서 요약을 본 것만으로 최초 상세 확인을 저장하지 않는다. 실제 S-08 진입 시 서버의 확인 처리를 연동한다.
- 잠금 안내가 열린 채 공개 시각이 지나도 원문을 자동 노출하지 않는다. 서버 상태 확인 후 ‘걱정 확인하기’를 제공한다.
- 공개 후에는 공개 시각 변경 진입을 숨기며 이미 공개된 기록을 다시 잠그지 않는다.
- 삭제·공개 시간 변경 후 홈·목록·시트와 관련 예약 상태를 일관되게 갱신한다.

### 상세·회고·요약 수정

- S-08 표시 순서: 과거 걱정 회고 → 현재 원문·선택 메모 → AI 정리 → 지금 불안도 → 과거 경험 → 도움 4종.
- 회고는 대상이 있을 때 최대 1개, ‘오늘은 건너뛰기’ 후 같은 날 다시 제안하지 않는다.
- 회고 선택은 괜찮아짐 / 진행 중 / 걱정대로 됨. 회고 대상 ID와 현재 걱정 ID를 혼동하지 않는다.
- 불안도는 1~5 선택형이며 건너뛸 수 있고 재입력은 덮어쓴다.
- 요약 수정은 공백 제외 1자 이상·최대 500자. 원문은 읽기 전용이다.
- 수정본은 이후 상세·목록의 표시에서 우선한다. 액션·휴식·공감 콘텐츠를 자동 재생성하지 않는다.
- 과거 경험은 최대 1개. ‘도움 됨’ 응답이 있어야 도움이 되었다는 표현을 쓴다. 상세 이동 대상은 S-14다.
- 도움은 네 가지 모두 보이며 AI 추천 1개만 강조한다. 추천과 다른 선택도 허용한다.
- 다른 진행 활동이 있으면 중단 확인 후 바꾸며, 체크 상태·과거 활동 이력은 보존하고 중단을 실패로 기록하지 않는다.

### 파쇄·기록 삭제

- 파쇄 확인에는 원문·선택 메모, AI 정리·추천, 활동 기록, 회고·평가, 알림 예약의 삭제 범위를 알린다.
- 실제 삭제·검색·캐시·예약 취소는 백엔드와 연동할 사항이다. 프론트 연출만으로 삭제 완료를 주장하지 않는다.
- 성공 응답 전에는 완료 화면으로 이동하지 않는다. 네트워크 응답 유실로 결과를 모르면 성공으로 안내하지 않는다.
- 파쇄 완료 → 홈 S-02 또는 금고 S-07. S-13 평가 화면을 띄우지 않는다.
- 공개 전 삭제와 기록 상세 삭제는 파쇄와 같은 삭제 범위를 쓰되 파쇄 연출 없이 목록으로 복귀한다.
- 취소는 데이터 변경 없이 원래 안내·상세로 돌아간다.

### 액션·휴식·공감 완료

| 활동 | 진행·저장 | 명시적 완료 | 중단 |
| --- | --- | --- | --- |
| 10분 액션 | 시작 시각·3단계 체크 상태, 체크 순서 자유, 저장 실패 표시 | 3개 체크 후 ‘전체 완료’ 성공 → S-13 | ‘나중에 이어하기’ → S-02, 체크 유지 |
| 짧은 휴식 | 기본 3분, 자동 시작 없음, 시작·종료 예정 시각 저장 | 0초가 되어도 자동 완료 아님. 완료 성공 → S-13 | 그만두기 확인 → S-08, 완료 아님, 다시 시작 시 3분 |
| 그냥 들어줘 | 봉인 때 생성된 공감 메시지 1회 재사용 | ‘읽었어요’ 저장 성공 → S-13 | 조회만으로 완료하지 않음 |
| 걱정 파쇄 | 서버의 실제 삭제 결과 확인 | 삭제 성공 → 전용 파쇄 완료 | 취소 시 변경 없음, 평가 없음 |

- 휴식은 실행 중 화면을 떠나도 시간이 흐르고, 일시정지 상태에서 떠나면 정지를 유지한다.
- 복귀 시 저장된 상태와 종료 예정 시각으로 복원하고 남은 시간은 최소 0으로 표시한다.
- 일시정지·재개 시 남은 시간·종료 예정 시각을 갱신한다. 확인창에서 ‘계속하기’는 타이머를 유지한다.
- 활동 완료와 도움 평가 저장은 별개다. 평가가 실패해도 이미 성공한 활동 완료를 취소된 것처럼 안내하지 않는다.
- 도움 평가는 기본값 없이 선택형이며 평가 없이 화면을 나가도 완료는 유지한다.

### 기록·시연

- S-14는 공개된 미삭제 기록만 최신순으로 표시한다. 잠긴 기록은 S-07에서 확인한다.
- 불안도 전후가 모두 있을 때만 비교한다. 미기록을 0으로 바꾸거나 치료·성공·실패 판정을 만들지 않는다.
- 기록 상세를 열 때마다 인증·공개·삭제·만료 상태를 재검사한다.
- S-18은 일반 내비게이션에서 제외하고 서버 권한 검사 후 제공한다.
- 타임머신은 시연 기록 공개 상태만 바꾼다. 실제 사용자 기록·실제 알림에는 영향이 없어야 한다.
- 기본 프리셋·장애 응답·초기화는 예시 데이터로 구분한다. 장애용 프리셋을 실제 AI 응답처럼 표시하지 않는다.

- 불안도: 선택 저장·덮어쓰기·미기록 구분, 삭제·만료 중 저장 요청의 처리.

- [ ] 최초 실제 진입 시각 처리가 새로고침으로 중복 기록되지 않는지 서버 계약을 확인한다.
- [ ] 회고 대상이 없으면 카드가 숨고, 있으면 최대 1개만 보인다.
- [ ] 회고 응답이 현재 걱정이 아닌 올바른 과거 기록에 저장된다.
- [ ] 당일 회고 건너뛰기 후 재제안하지 않는다.
- [ ] AI 요약의 최소·최대·공백 조건과 저장 실패 처리가 맞는다.
- [ ] 요약 취소는 변경하지 않고 돌아가며, 성공은 목록과 상세에 수정본을 반영한다.
- [ ] 요약 수정이 원문이나 이미 생성된 도움 콘텐츠를 바꾸지 않는다.
- [ ] 선택형 불안도 건너뛰기·재입력·저장 실패가 구분된다.
- [ ] 과거 경험은 최대 1개이며 실제 평가에 근거해 표현하고 올바른 S-14로 이동한다.
- [ ] 네 가지 도움을 모두 고를 수 있고 추천은 하나만 강조된다.
- [ ] 활동 변경 취소 시 기존 활동을 유지하고, 확인 시 체크·이력을 보존한다.

### 파쇄·기록 삭제

- [ ] 삭제 대상을 작성 일시 등으로 식별하고 삭제 범위·되돌릴 수 없음을 표시한다.
- [ ] 취소는 데이터를 바꾸지 않는다.
- [ ] 실패·응답 유실·불명확 결과에서 완료 연출·성공 문구를 먼저 보여주지 않는다.
- [ ] 성공 후 홈·금고·기록·과거 경험에서 삭제된 데이터가 다시 보이지 않는다.
- [ ] 공개 전 삭제와 기록 삭제에는 파쇄 연출이 없고, 파쇄 완료에는 S-13 평가가 없다.
- [ ] 연출·소리가 없어도 일반 버튼으로 실행하고 결과를 읽을 수 있다.

### 액션·휴식·공감·완료

- [ ] 액션 체크 순서는 자유이고 3개 전에는 전체 완료가 비활성이다.
- [ ] 3개 체크만으로 완료되지 않고 명시적 전체 완료 저장 성공을 확인한다.
- [ ] 체크 저장 실패를 표시하며 중단·재진입 후 저장된 체크를 복원한다.
- [ ] 나중에 이어하기 후 S-02 진행 중 활동 카드가 반영된다.
- [ ] 휴식은 사용자가 시작하기 전 흐르지 않는다.
- [ ] 일시정지·재개·백그라운드·복귀에서 타이머를 저장된 기준으로 복원한다.
- [ ] 남은 시간이 음수가 되지 않고 0초가 되어도 자동 완료되지 않는다.
- [ ] 그만두기 취소는 타이머 유지, 확인은 완료가 아닌 S-08 복귀다.
- [ ] 그만두기 후 다시 시작하면 3분부터 시작한다.
- [ ] 공감 화면에 채팅 입력창·매번 새 AI 생성·조회 즉시 완료 처리가 없다.
- [ ] 읽었어요 저장 성공 후에만 S-13으로 이동한다.
- [ ] 평가 기본값이 없고 건너뛰어도 활동 완료는 유지된다.
- [ ] 평가 실패와 활동 완료 실패를 혼동하지 않는다.
- [ ] 홈으로는 S-02, 다음 걱정 보기는 S-07로 이동한다.

### 기록·시연·공통

- [ ] S-14에서 잠긴 기록과 삭제·만료된 기록이 제외된다.
- [ ] 전후 불안도 중 하나가 없으면 비교 수치를 만들지 않는다.
- [ ] 기록 빈 상태는 다음 행동을 제공하고, 과거 경험에서 기록 상세 진입이 작동한다.
- [ ] S-18 접근은 서버 권한을 검사하고 일반 메뉴에서 노출하지 않는다.
- [ ] 시연 공개 전환·초기화는 실제 기록·실제 알림에 영향을 주지 않는다.
- [ ] 네트워크 장애 프리셋에 예시·장애 대체 응답임을 표시한다.
- [ ] 로딩·빈 상태·오류·재시도와 완료 여부 불명확 상태를 화면별로 처리한다.
- [ ] 작은 선택 버튼도 실제 터치 영역을 확보하고 텍스트 대비·움직임 감소·무음 사용을 지원한다.
- [ ] 내용·상태를 색·소리·연출만으로 전달하지 않는다.
- [ ] 실제 모바일 웹 안전영역·스크롤·키보드·뒤로가기에서 주요 버튼과 문구를 확인한다.
