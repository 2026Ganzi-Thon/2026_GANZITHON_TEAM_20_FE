# 간지톤 — 심야 걱정 금고 (Wooly Vault)

개발을 시작하기 전에 `WOOLY_VAULT_PLAN.md`를 읽고 서비스 정책과 담당 범위를 확인한다.

화면 구현 전에는 `WOOLY_VAULT_WIREFRAMES.md`에서 해당 화면의 원문·상태·가이드·연동 기준을 확인한다. 2026-11-12에 와이어프레임 페이지의 9개 영역, 43개 화면·상태·패턴 프레임, 40개 화면정의 가이드와 1,171개 텍스트 노드를 조회해 저장했다. 프로토타입 반응은 없었으며 이동 관계는 가이드와 레이어명 근거다.

**사용자 지시: Figma 안의 작업물을 절대 변경하지 않는다.** Figma는 조회만 하고, 생성·수정·삭제·디자인 재배치 등 원본 변경을 수행하지 않는다. 이후 사용자가 이 지시를 명시적으로 바꾸기 전까지 유지한다.

- 사용자는 프론트엔드 **FE2** 담당이다.
- 담당 범위: **금고·잠금 안내·상세·도움 활동·회고·기록·시연**.
- 기획안 전체 핵심 구현 목록을 사용자 개인의 담당 범위로 확대하지 않는다.
- 프레임워크, API 필드 등 미확정 사항은 기존 프로젝트 코드와 팀 설계 문서에서 확인한다.
- 최신 사용자 지시와 이후 제공되는 기능명세·디자인·API 문서를 반영한다.

## UI·나이트·컴포넌트 디자인 기준 (2026-11-15)

- 화면 구현 전 `WOOLY_VAULT_DESIGN.md`의 해당 화면 이미지·문구·수치·가이드·충돌 목록을 읽는다. 사용자 요청은 원본 디자인 재현이며, 임의의 레이아웃·문구·아이콘·색 변경을 하지 않는다.
- 원본 보존 묶음은 `WOOLY_VAULT_DESIGN_EVIDENCE.zip`이다. `design_sources/`에 원본, `design_analysis/`에 화면 크롭·좌표 JSON·SVG 렌더가 있다.
- 확인 범위는 제공 ZIP의 PDF10개·PNG15개·SVG18개, PDF의390폭 프레임41개와 가이드42개다. Figma 전체 나이트 화면이나 모든 레이어를 확인 완료했다고 확대하지 않는다.
- 시안/가이드 충돌을 숨기지 않는다. 정리 수정의 저장 불가 시안은 disabled처럼 보이지만 가이드는 클릭 허용을 명시한다. 1/3 액션에서도 전체 완료 버튼은 동작상 비활성이다. S-08 실제 PDF 높이1181와 가이드1224를 구분한다.
- 나이트는22:00~06:00 시각 기준이며 플로우와 무관하다. 나이트 기준의 미정 토큰과 남은 검정 아이콘·단계바 색은 디자인 MD를 확인한다. PDF/PNG에서 Auto Layout·모션·반응형 원본 값을 확인한 것으로 단정하지 않는다.
- 프론트 기술 스택은 사용자 확정 **React / Vite / JavaScript / CSS / React Router / Axios**다.
- FE1은 `src/styles/typography.css`, `src/styles/colors.css`를 `main.jsx`에서 가져오고 main에 머지했다고 공유했다. 사용 예는 `title-1`, `var(--gold-200)`이다. 2026-11-15에 `frontend/`로 팀 저장소를 받아 main `698aebf`의 실제 공통 CSS·패키지를 확인했다. 로컬 `feat/fe2`에서 구현했으며 실행·라우트·연동 기준은 `frontend/docs/FE2_IMPLEMENTATION.md`, 검증 결과와 남은 차이는 `frontend/docs/FE2_QA.md`에 기록했다. 이후 작업에서도 최신 팀 코드를 확인하며 확정되지 않은 경로·DTO를 추측하지 않는다.

## API 연동 참고 자료

- `WOOLY_VAULT_API_INTEGRATION.md`: BE1·BE2·AI 통합 문서 25쪽 전체 및 FE2 화면별 API 연결표·상태·요청값·확인 필요 항목.
- `WOOLY_VAULT_SWAGGER_API.md`: Swagger 문서 90쪽 전체, operation 50개·schema 57개 색인과 FE2 참고사항.
- 두 API 문서의 원본은 2026-11-09 기준 draft이며 **팀 합의 전 설계 제안**이다. 실제 서버·배포·검증이 완료되었다고 가정하지 않는다. 최신 YAML 원본과 백엔드 확정 계약을 확인한다.
- DELETE 202는 작업 접수다. 삭제 job COMPLETED 또는 명세의 즉시 완료 204 전에는 파쇄 성공을 표시하지 않는다.
- ACTION pause는 STOPPED+체크 유지, REST pause는 PAUSED+잔여시간 고정이라는 초안을 구분한다. REST stop 이후 새 시작은 180초다.
- 회고 후보·nullable·완료 상태 코드·요약 동시성 등은 위 문서의 근거와 미정 사항을 확인한다. PDF 인쇄 표를 자동 생성 가능한 완전한 OpenAPI YAML로 간주하지 않는다.

## 백엔드·AI 구현 현황 (2026-11-15 공유 반영)

- `WOOLY_VAULT_BACKEND_AI_STATUS.md`에서 최신 팀 공유 원문, 기술 구성, 검증 결과와 검토 중인 항목을 확인한다.
- 공유된 구성: Java 21 / Spring Boot 4.1.2 / Spring Security / PostgreSQL 17 / Flyway / Gradle / Docker Compose, AI는 Python / FastAPI / Upstage Solar Mini 4.
- 모바일 웹 → 단일 Spring 백엔드 → Python 내부 API → Solar API. FE는 Spring만 호출한다. BE1·BE2 담당 구분을 별도 배포 서버 2개로 단정하지 않는다.
- 현재 검증 구성에서 Solar 전송 데이터는 걱정 원문만이다. 합성 3건, 로컬 제출~완료 약 3.1~3.9초는 팀 보고이며 운영 성능 보장이 아니다.
- 게스트 쿠키·토큰 해시·CSRF·게스트 소유권·AES-256-GCM·접수 후 30일 만료 구현이 공유됐다. 실제 위기 기준/S-16 연동은 모의 검증 단계이고, 품질 재평가·외부 전달 범위·운영 로그 점검은 진행 중이다.
- 이 공유로 API draft의 모든 경로·DTO가 구현 완료되었다고 가정하지 않는다. 실제 코드·최신 확정 계약을 확인한다.

## 2026-11-15 FE2 통합 준비 추가 기록

- 실제20팀 백엔드 TEAM_20_BE develop `213b5a7a13c33378cf7fa16a3780382a802ca79c`를 조회했다. PDF 초안과 실제 경로/DTO가 달라 `frontend/src/features/fe2/springContract.js`에 운영 매핑을 구현했다. 최신 기준은 `frontend/docs/FE2_HANDOFF.md`다. 실제 서버 실행·운영 API 검증 완료로 확대하지 않는다.
- `npm run check:release`는 린트·24개 테스트·빌드·예시 fixture 제외 검사를 실행한다. 날짜 팝업은 제공 달력 참고 구조로 교체했고 빈 기록의 자리표시자 문구는 기존 금고 아이콘으로 대체했다. Figma 원본은 변경하지 않았다.
- 실제 DELETE202는 `{status:DELETING}`이고 현재 조회한 서버에는 완료 job/status API가 없다. FE에서 완료를 추정하지 않으며, 출시 전 완료 판정 계약이 필요하다. FE1 홈/입력/설정 완성 코드 머지와 실제 쿠키/CSRF/서버 E2E 검증도 남아 있다.

## 최신 디자인 재검수 우선 기준

- 사용자의 원본 동일 재현 지시로 Figma UI/나이트 메타데이터 및32개 FE2·공통·참고 프레임을 조회했다. 원본 변경은 하지 않았다. 최신 구현 근거와 확인 범위는 `frontend/docs/FE2_DESIGN_RECHECK.md`다. 전체 Figma 모든 레이어 확인으로 확대하지 않는다.
- 금고16/24·보조12/20 등 개별 스타일과 SUITE/Noto Sans KR 혼용을 실제 노드별로 보존했다. 기존 금고 아이콘으로 빈 상태를 대체한 변경은 취소했고 원본의 자리표시자를 복원했다. 경고 입력란에 임의 분홍 테두리를 넣지 않는다.
- 개발용 비교 상태바와 앱 바깥 모드 도구만 제공한다. 운영에 가짜 상태바/고정 예시를 넣지 않는다. Git 커밋·푸시/FE1 통합은 디자인 재검수 때문에 아직 수행하지 않았다.
