## 기능 확인

- 저장 불가 버튼은 눌러 오류를 확인하며, 저장 실패 시 초안이 유지된다.
- 액션 3체크·휴식 0초·공감 읽기는 자동 완료하지 않고 명시적 완료 버튼을 요구한다.
- 활동 전환 취소와 액션 체크 유지, 휴식 일시정지·복귀·재개·중단 후 새180초를 확인했다.
- 서버 시계 갱신 간격 때문에 시작 직후03:01이 표시되던 문제를 수정하고 경계 테스트를 추가했다.
- 공개 시각까지 잠김 원문 비노출, 공개 경계 재조회, 재잠금 금지를 확인했다.
- 파쇄는202 접수 후 완료를 표시하지 않고 job COMPLETED/204 뒤에만 성공한다.
- 회고 건너뛰기·응답, 불안도 저장, 평가 선택/건너뛰기, 기록 삭제 취소, 시연 초기화를 확인했다.
