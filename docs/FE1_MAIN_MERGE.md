# 최신 main 반영

반영 대상: main 60c45c389c8588aaa31ac0c1f2c5dadf3f0d0f8b. 작업 브랜치: feat/fe2.

- FE1의 시작 화면, 게스트 생성·만료 분기, 홈 금고 요약 API, 공통 하단 메뉴와 lucide 의존성을 보존했다.
- App 라우팅 충돌을 해결했다. FE1 페이지에는 FE1 게스트 확인을, FE2 페이지에는 기존 FE2 세션 처리를 적용한다. /demo는 기존 운영자 인증을 유지한다. 기록 화면은 FE2 레이아웃만 사용한다.
- 홈의 금고 열기·잠긴 걱정 보기는 /vault, 기록 탭은 /records로 연결한다. FE2 변경 이벤트에서 홈 요약을 다시 조회한다. 요약 누락 시 잠김 2개를 임의 표시하던 기본값은 0으로 바꿨다.
- 빈 기록의 걱정 맡기기는 FE1에서 확인된 /worry-input 경로로 연결했다.
- Vite의 API_PROXY_TARGET 설정을 유지하고, 미설정 시 FE1 기본값 http://127.0.0.1:8080을 사용한다.
- VITE_FE2_MOCK=true인 개발 모드에서만 FE1 홈 요약도 FE2와 같은 예시 엔진을 조회한다. 배포 빌드에는 예시 엔진을 포함하지 않는다.

## 검증

- npm ci: 취약점 0개 보고. npm run check:release: 린트, 테스트 24개, 배포 빌드, 예시 데이터 배포 제외 검사 통과.

## 남은 팀 작업

최신 main의 /worry-input은 FE1이 남긴 임시 화면이며 /settings도 기존 임시 문구 화면이다. 이번 main 병합으로 두 화면의 구현 완료나 서비스 출시 완료를 의미하지 않는다. 실제 서버·쿠키·데이터 흐름 검증과 기존 FE2_HANDOFF의 백엔드 미확정 사항은 남아 있다.
